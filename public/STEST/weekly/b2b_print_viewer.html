갓통과 B2B 인쇄 정책 & 원내 복합기 최적 출력 가이드

1. 보안 인쇄 정책 및 PDF 원본 미제공 배경

• PDF 원본 파일 배포 금지: 제휴 학원의 소중한 수강료 가치와 주간지 콘텐츠의 무단 복제 및 외부 유출(텔레그램, 타 학원 유출)을 원천 차단하기 위해 본사는 주간지 원본 PDF 파일 다운로드를 일체 제공하지 않습니다.
• 웹 뷰어 보안 직출력: 계약된 인원 내에서 암호화된 전용 웹 뷰어를 통해 학원 복합기로 직접 출력하는 [보안 다이렉트 인쇄]만 지원됩니다.
• 정품 시리얼 워터마크 각인: 출력되는 모든 A4 페이지 하단 여백에 [학원명 연구팀] ‧ PUB-ID: ... ‧ VERIFIED 고유 식별 코드가 실시간 자동 각인되어 인쇄물 유출 시 유출자를 즉시 특정할 수 있습니다.

2. 브라우저 인쇄 필수 설정 (Ctrl+P 인쇄 창)

① 여백: [없음 / None] 여백을 '없음'으로 설정해야 500px 캔버스가 물리적 A4 용지 전체(210×297mm)에 100% 꽉 차게 자동 배율 확대 출력됩니다.
② [배경 그래픽 포함] 필수 체크 체크를 켜야 표지 그라데이션, 문항 음영 박스, 개념 요약표 등 컬러/도표 배경이 빠짐없이 선명하게 인쇄됩니다.

3. 원내 복합기 최적 인쇄 노하우 (PDF 유출 0% 완제품 책자)

추천 1위 ⭐ 복합기 드라이버 [A3 소책자 (Booklet) 중철 인쇄] (시중 주간지 완제품)

• 설정: 브라우저 인쇄창에서 학원 복합기(신도리코/제록스/캐논 등) 선택 ➔ [속성/설정] ➔ [소책자 인쇄 (Booklet)] 활성화 + 용지: A3(또는 B4)
• 결과: 복합기가 A4 4개 면을 A3 앞뒤 양면으로 책 순서에 맞게 자동 배치하여 출력합니다. (16p 교재 기준 A3 용지 딱 4장 소요)
• 완성: 출력된 4장을 반으로 접어 가운데에 롱호치키스(스테이플러)를 찍으면 시대인재·이감 주간지와 동일한 고품질 완제품 책자로 완성됩니다. (종이/토너 50% 절감!)

기본형 일반 A4 양면 인쇄 (긴 쪽으로 넘김)

일반 A4 용지로 출력 시 [양면 인쇄(긴 쪽으로 넘김)]를 선택하고, 좌측 상단/모서리에 2방 스테이플러나 슬라이딩 바인더를 끼워 배부합니다.
