questions.score		 Number 문항 배점 (1.5점, 2.0점, 2.5점). 시험지 배점표와 자동 동기화.
정답 번호 q-answer questions.correctAnswer Number (1~5) 5지 선다형 정답 번호. 시험지 정답표와 자동 동기화.
문항 이미지 경로 q-image-url questions.image_path String Storage 또는 로컬 이미지 CDN 절대 URL 경로
문항 저장 시 자동 연쇄 업데이트 동작 원리
  • exams 컬렉션 동기화: 해당 문항이 포함된 모든 시험지 문서의 `questions` 배열, `score_map`, `answer_key`를 즉시 일괄 수정합니다.
  • 분석 아카이브 동기화: `artifacts/.../exam_archive` 문서의 토픽(`topic`) 및 행동영역(`domain`)을 최신화합니다.
  • 학생 오답노트 동기화: 모든 학생의 `users/{uid}/wrong_answers` 컬렉션 그룹을 검색하여, 해당 문항의 단원 및 행동영역을 최신 정보로 실시간 동기화합니다.
master_db.json 파일 업로드 자동 파싱 & 분배 매핑 (UI 함수: processMasterDbSync)

관리자가 `master_db.json` 파일을 드래그하거나 선택하여 업로드하면, JSON 내부 속성을 자동으로 분석하여 4개 핵심 DB 컬렉션으로 분배 저장합니다.

관리자 및 개발자를 위한 파이어스토어 무결성 3대 원칙

1. undefined 값 절대 금지

Firestore SDK는 객체 내에 undefined가 포함되면 즉시 쓰기 트랜잭션을 중단시킵니다. 데이터 저장 전 항상 기본값 할당 또는 sanitizeForFirestore() 필터를 거쳐야 합니다.

2. 원자적 카운트 필드 사용

전국 응시자 수, 오답 횟수 등 동시 다발적으로 증가하는 수치는 단순 덮어쓰기가 아닌 increment(1) 또는 runTransaction()을 사용해야 데이터 유실이 없습니다.

3. 표준 3종 ID 규칙 준수

패키지 및 시험지 ID는 과거의 임의 명칭 대신 infinity_2028, week_2028, mock_2028_s0 및 week_2028_01~10 공통 규격을 100% 준수해야 합니다.
